    How a brief is made

    1. Scan. Each .gov URL is fetched and reduced to readable text. On a server deploy, a Worker validates the .gov host, DNS, redirects, size, and timeouts first.
    2. Split and rank. Text is cut into sentence-level passages, then scored by rare-term overlap across the whole collection.
    3. Cite. The brief quotes the top passages verbatim and tags each with its source, so every line can be checked.
    4. Answer. Questions retrieve the best-matching passages. With Grok connected, only those passages are sent, marked as untrusted data.
